# 아임인 프로모션코드 안내 랜딩페이지

- 코드: `ZGK29HT3I1`
- 배포 대상: `https://im-in.tire210.com/`
- 정적 HTML/CSS/JS. 빌드 과정 불필요.

## 배포
GitHub 저장소 `imin-promo-guide-kr` 최상위에 파일을 업로드하고 Vercel에서 해당 저장소를 Import합니다. Framework Preset은 Other, Output Directory는 비워둡니다.

Vercel Settings > Domains에서 `im-in.tire210.com`을 추가하고 표시되는 DNS 레코드를 호스팅케이알의 `tire210.com` DNS 설정에 추가합니다. 기존 DNS 레코드는 유지합니다.

도메인이 연결되면 검색엔진 등록 및 사이트맵 제출을 진행하세요. 네이버/구글 소유확인 메타태그는 **이 도메인에서 발급받은 값**을 확인 후 `index.html`의 head에 넣으세요.

이 페이지는 공식 아임인 사이트가 아니며, 혜택은 앱의 최신 공지에 따라 달라질 수 있습니다.
